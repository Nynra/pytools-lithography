# Pytools-Lithography

DEPRECATION (NO LONGER USED) NOTICE: This repository is no longer used to host the Pytools Lithography package as the package has been split in two, [`pytools-litho-design`](https://github.com/Nynra/pytools-litho-design) for mask design and [`pytools-litho-analysis`](https://github.com/Nynra/pytools-litho-analysis) for SEM image analysis. Please refer to the new repositories for the latest versions of the packages or extra info and examples.

This repository is only used to host the documentation for `pytools-litho-analysis` and `pytools-litho-design`.

## My report references the Pytools Lithography package, where can I find it?

The `pytools-lithography` is deprecated but if you really want to reference it (and not the new packages) you can find the old versions in the commit history. As the report probably references the latest version of the package and not a specific commit you should choose one near the release date of the report.

**The only reason you should do this is to verify result in the report. For doing new work you should use the new packages.**
