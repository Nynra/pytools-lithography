# Pytools Lithography Examples

As `pytools-lithography` is just a wrapper for `pytools-litho-design` (for mask design) and `pytools-litho-analysis` (for sem image analysis), the examples here would be replicates of the examples in the respective repositories. As that would add unnecessary maintainance work, the examples are not replicated here. Instead, the examples are linked below:

- [Examples for `pytools-litho-design`](https://github.com/Nynra/pytools-litho-design/tree/main/examples)
- [Examples for `pytools-litho-analysis`](https://github.com/Nynra/pytools-litho-analysis/tree/main/examples)
